# TaskFlow - DevOps Capstone Project

## Project Overview
TaskFlow is a simple Task Management Application deployed
using Docker, Docker Compose and AWS EC2.

## Application Architecture
- Frontend: HTML, CSS, JavaScript and Nginx
- Backend: Python and Flask
- Database: PostgreSQL

## DevOps Technologies
- Linux
- Docker
- Docker Compose
- AWS EC2
- Git and GitHub
- Terraform
- Ansible
- Prometheus
- Grafana
- Alertmanager

## Project Objectives
- Containerize frontend, backend and database.
- Manage services using Docker Compose.
- Deploy the application on AWS EC2.
- Configure networking and security.
- Implement health checks and logging.
- Monitor application infrastructure.

## Deployment Status
Development in progress.
